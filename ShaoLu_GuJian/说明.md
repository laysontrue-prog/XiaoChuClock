# ⚠️ 编译/烧录必看（不这样设一定报错）

## 一、Arduino IDE 必须设置的 5 项

打开 `Ardui_TQSZ/Ardui_TQSZ.ino` 后，在「工具」菜单里逐项确认：

| 菜单项 | 必须选 |
|---|---|
| 开发板 | **ESP32C3 Dev Module** |
| **Partition Scheme（分区方案）** | **Huge APP (3MB No OTA/1MB SPIFFS)** ← ★最关键 |
| Flash Size | **4MB (32Mb)** |
| Flash Mode | **DIO** |
| Upload Speed | **115200** |
| CPU Frequency | 160MHz (WiFi) |

### 为什么 Partition Scheme 必须选 Huge APP

固件大约 **3.0 MB**，而各分区方案的程序区上限是：

```
默认分区（Default 4MB with spiffs）  → 1.25 MB   ✗ 会报 "Sketch too big / text section exceeds available space"
Huge APP (3MB No OTA/1MB SPIFFS)    → 3.00 MB   ✓ 放得下，还剩约 140 KB
```

**报错长这样就是分区选错了（不是代码太大）：**
```
Sketch uses 3005416 bytes (229%) of program storage space. Maximum is 1310720 bytes.
Compilation error: text section exceeds available space in board
```
→ 把 Partition Scheme 改成 **Huge APP** 即可，代码一行都不用改。

## 二、填自己的天气 Key（两步，30 秒）

代码里天气相关全部是**可配置**的，默认值能直接编译（只是没天气数据）。

### 第 1 步：复制模板

在 `Ardui_TQSZ/` 目录下把 `secrets.h.example` 复制一份，改名为 `secrets.h`：

```bash
cp secrets.h.example secrets.h
```

Windows 上就是：右键 `secrets.h.example` → 复制 → 粘贴 → 重命名成 `secrets.h`

### 第 2 步：填 3 行

打开 `secrets.h`，按你的账号填写：

```cpp
// ① API Key —— 到 https://console.qweather.com/ 申请（免费）
#define KEY "你的32位Key"

// ② API 域名 —— 大多数账号【不用改】，保持下面两行默认值即可
#define QW_GEO "https://geoapi.qweather.com"
#define QW_API "https://devapi.qweather.com"
```

保存后重新编译烧录即可。

### ★ API Host 在哪看（这一步最容易卡住）

**控制台 → 左侧「设置」** → 页面上就有 **API Host**（不是"项目管理"、也不是"凭据"页）：

```
形如：h2a9cf3mhs.xy.qweatherapi.com
```

把它填进 `secrets.h`：

```cpp
#define QW_GEO "https://hxxxxxxx.xy.qweatherapi.com/geo"   // 城市查询，末尾要带 /geo
#define QW_API "https://hxxxxxxx.xy.qweatherapi.com"       // 天气，不要 /geo
```

> **为什么必须填**：和风从 2024 年起把 API Host 作为身份认证的一部分，
> 新账号用公共域名会直接返回 `403 Invalid Host`；
> 而且官方公告：**2026 年起公共地址 `devapi/geoapi` 会逐步停止服务**。
> 所以推荐所有账号都填自己的 API Host。

**验证是否填对**（换成你自己的 host 和 KEY）：

```
https://你的host/v7/weather/now?key=你的KEY&location=101010100
```

返回 JSON 天气数据 = 成功 ✓　返回 `403 Invalid Host` = host 填错了 ✓

---|---|
| **没有 API Host**（大多数账号都是这样）| **不用改**，只填 `KEY` 就行 ✓ |
| **有 API Host**（形如 `abc123.re.qweatherapi.com`）| 两行都改成它：<br>`#define QW_GEO "https://abc123.re.qweatherapi.com/geo"`<br>`#define QW_API "https://abc123.re.qweatherapi.com"` |

注意：城市查询那行末尾要多一节 `/geo`，天气那行不用。

**拿不准的话**，在浏览器地址栏打开下面这个链接（把 KEY 换成你的）验证一下：

```
https://devapi.qweather.com/v7/weather/now?key=你的KEY&location=101010100
```

- 返回一串 JSON 天气数据 → **不用改**，只填 KEY ✓
- 返回 401 / `API key is not valid` → 你的账号有专属 Host，按上表改 ✓
